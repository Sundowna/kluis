Get the official Proton Drive CLI

One click downloads it from proton.me and checks Proton’s SHA-512 checksum. Kluis never touches your files any other way.

{{cliNote}}

Sign in to Proton

Your browser opens Proton’s own sign-in page. Kluis never sees your password; the session is kept in your system keyring.

{{signNote}}

On KDE Plasma, if sign-in isn’t remembered, install gnome-keyring and log in again.

Pick folders to sync

Each starts as two-way sync. You can change that per folder later.
