**Kluis**: unofficial Proton Drive desktop client for **Linux Mint** and **EndeavourOS**, built on Proton's official Proton Drive CLI.

### Install
- **Linux Mint / Ubuntu / Debian:** download `kluis_latest_all.deb` below and double-click it.
- **EndeavourOS / Arch / Manjaro:** in a terminal:
  ```
  curl -LO https://github.com/Sundowna/kluis/releases/latest/download/kluis-latest-any.pkg.tar.zst
  sudo pacman -U kluis-latest-any.pkg.tar.zst
  ```
Then start **Kluis** from your app menu.

### What's in it
- Synced folder list: two-way, back up, or mirror down, per folder
- Proton Photos: save your phone's photos locally (by month/year), add photos from a folder, gallery with photo and video previews
- Panel icon (XApp on Cinnamon/MATE/Xfce, system tray on KDE Plasma), Drive browser, activity log, notifications
- Safe by design: nothing deleted for good (Trash only), conflicts keep both copies

### Status
Early release: tested against a stand-in for the CLI, not yet against a live Proton account. Try it on a test folder first.
